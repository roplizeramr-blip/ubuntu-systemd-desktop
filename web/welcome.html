Welcome to your Ubuntu desktop

A real XFCE X11 session served by KasmVNC. Chrome, a terminal, the file manager and a systemd-compatible service layer are installed. Use it like a normal Ubuntu workstation.

Ubuntu 24.04 XFCE Google Chrome KasmVNC Supervisor

Quick start

  • Launch Google Chrome to browse the web.
  • Open Terminal for a shell.
  • Use Systemd Compatibility Info to inspect the service layer.
  • Change the Linux password with sudo passwd desktop.

Access

The desktop is served on the app's public HTTPS URL and always asks for the KasmVNC credentials. The VNC user is admin; its password is the deployment's VNC_PW.

Linux user: desktop (member of sudo). Set or change its password from a terminal with sudo passwd desktop.

systemd layer

Supervisor is PID 1 and the compatibility layer exposes the usual interfaces:

systemctl status
systemctl is-system-running
systemctl list-units --type=service
hostnamectl
journalctl -n 30

This is a compatibility facade, not the real systemd PID 1. It exists because a container has no init system; it is not a security boundary.

Useful commands

sudo apt update
google-chrome --version
systemctl status kasmvnc
systemctl restart xfce
df -h
free -h

Files and storage

Your home directory is /home/desktop. Files live inside the container and may be lost if the app is redeployed or deleted. Download important files to your own computer.

Security

Use a strong VNC_PW, keep the app URL private, and avoid storing secrets in the desktop. The public endpoint is protected by HTTPS and KasmVNC Basic Auth.
