سطح مكتب Ubuntu على السحابة
============================

Ubuntu 24.04 + XFCE + Google Chrome، يُعرض في المتصفح عبر noVNC.
بدون Tailscale وبدون أي وكيل ذكاء اصطناعي.

الحزمة الجديدة (أخف بكثير):
----------------------------
- TigerVNC هو خادم X (عملية واحدة، RFB على 127.0.0.1 فقط).
- noVNC + websockify: المتصفح يفُكّ الترميز، فالخادم لا يدفع ثمن الترميز.
- nginx هو المنفذ العام الوحيد: المصادقة، صفحة الحالة، وتمرير WebSocket
  بنفق nginx نفسه (لا سوكيت Python في المسار) فلا ينقطع الاتصال.
- سبع خدمات فقط تحت Supervisor: dbus, vnc, websockify, xfce, nginx,
  control, earlyoom.
- لا KasmVNC، ولا محاكاة systemd داخل الحاوية.

المستودع:
https://github.com/roplizeramr-blip/ubuntu-systemd-desktop

خطوات النشر
-----------
1. ارفع المستودع إلى GitHub.
2. أنشئ تطبيقاً من المستودع:
   - Build: Dockerfile
   - Port: 3000
   - Health: /healthz
3. أضف متغيرات البيئة:
   PORT=3000
   CONTROL_PORT=3001
   WS_PORT=6080
   VNC_PORT=5901
   VNC_USER=admin
   VNC_PW=<كلمة سر قوية 6 أحرف على الأقل>
   DESKTOP_PW=<كلمة سر حساب لينكس>
   ROOT_PW=<كلمة سر root>            # اختياري
   VNC_RESOLUTION=1280x720
   VNC_AUTH=1
   PUBLIC_DESKTOP=1
   TZ=Africa/Cairo
   CHROME_AUTOSTART=1
   SWAP_ENABLED=0
4. اضغط Deploy وانتظر انتهاء البناء.
5. افتح رابط التطبيق:
   - /        → سطح المكتب (يسأل عن VNC_USER / VNC_PW، يتصل تلقائياً)
   - /status  → صفحة الحالة
   - /healthz → فحص الصحة

بيانات الدخول
-------------
VNC user: admin
VNC password: الذي تحدده في VNC_PW

Linux user: desktop
Linux password: الذي تحدده في DESKTOP_PW

لا تضع أي كلمة سر داخل المستودع أو داخل الصورة.

ملاحظات مهمة
------------
- مقبس سطح المكتب على 127.0.0.1:5901 فقط؛ nginx هو المدخل العام الوحيد.
- Xtigervnc يعمل بـ noreset وwebsockify بـ heartbeat: إعادة تحميل الصفحة أو
  نوم الجهاز لا تقطعان الجلسة.
- systemd الحقيقية تحتاج VPS/VM — راجع docs/DEPLOY-VPS.md:
  VNC_PW='كلمة سر' ./vps/install.sh
- الملفات داخل الحاوية وتضيع عند إعادة النشر.
- الصورة بلا GPU: Chrome يعمل بمحرك رسم برمجي.
