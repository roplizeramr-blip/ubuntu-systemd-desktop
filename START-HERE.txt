سطح مكتب Ubuntu على السحابة
============================

Ubuntu 24.04 + XFCE + Google Chrome، يُعرض في المتصفح عبر KasmVNC.
بدون Tailscale وبدون أي وكيل ذكاء اصطناعي.

المستودع:
https://github.com/roplizeramr-blip/ubuntu-systemd-desktop

خطوات النشر على CranL
---------------------
1. ارفع المستودع إلى GitHub.
2. في CranL أنشئ تطبيقاً من المستودع:
   - Build: Dockerfile
   - Port: 3000
   - Health: /healthz
   - Region: netherlands-1
3. أضف متغيرات البيئة:
   CONTROL_PORT=3000
   VNC_USER=admin
   VNC_PW=<كلمة سر قوية 6 أحرف على الأقل>
   DESKTOP_PW=<كلمة سر حساب لينكس>
   ROOT_PW=<كلمة سر root>            # اختياري
   VNC_RESOLUTION=1440x900
   VNC_FRAME_RATE=30
   VNC_AUTH=1
   PUBLIC_DESKTOP=1
   TZ=Africa/Cairo
   CHROME_AUTOSTART=1
   SWAP_ENABLED=0
4. اضغط Deploy وانتظر انتهاء البناء.
5. افتح رابط التطبيق:
   - /        → سطح المكتب (يسأل عن VNC_USER / VNC_PW)
   - /status  → صفحة الحالة
   - /healthz → فحص الصحة

ملاحظة: git push يبني الصورة لكنه لا يستبدل الحاوية العاملة،
لازم تعمل Deploy بعد البناء.

بيانات الدخول
-------------
VNC user: admin
VNC password: الذي تحدده في VNC_PW

Linux user: desktop
Linux password: الذي تحدده في DESKTOP_PW

لا تضع أي كلمة سر داخل المستودع أو داخل الصورة.

ملاحظات مهمة
------------
- KasmVNC يستمع على 127.0.0.1:6080 فقط؛ المنفذ العام الوحيد هو 3000.
- systemd داخل الحاوية محاكاة فوق Supervisor، وليست systemd حقيقية.
- systemd الحقيقية تحتاج VPS/VM — راجع docs/DEPLOY-VPS.md.
- الملفات داخل الحاوية وتضيع عند إعادة النشر.
- الصورة بلا GPU: Chrome يعمل بمحرك رسم برمجي.
